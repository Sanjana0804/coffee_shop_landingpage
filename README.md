# ☕ Brew & Bean

### A Modern Coffee Shop Landing Page

> **Brew. Sip. Relax.**

A creative and responsive coffee shop landing page designed with a warm, premium café aesthetic using **only HTML5 and CSS3**.

---

## ✦ About The Project

**Brew & Bean** is a modern coffee shop website concept created to showcase how a beautiful and responsive landing page can be built without JavaScript or CSS frameworks.

The design focuses on:

☕ Premium coffee experience  
🎨 Elegant visual design  
📱 Responsive layouts  
✨ Smooth CSS effects  
🧩 Clean and organized code  

---

## ✦ Features

- 🏠 Attractive Hero Section
- ☕ Coffee Shop Branding
- 📖 About Us Section
- 🍵 Coffee Menu
- 🍰 Food & Dessert Cards
- ⭐ Customer Reviews
- 📍 Contact Section
- 🦶 Modern Footer
- ✨ CSS Hover Effects
- 📱 Fully Responsive Design
- 🎨 Custom Color Palette
- 🖼️ Background Images
- 📐 CSS Grid & Flexbox
